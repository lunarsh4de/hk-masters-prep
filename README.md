# 港硕行前备忘录

面向内地赴港读硕学生的行前行动清单，覆盖出发前准备与抵港第一周。无需注册和后端，可直接部署到 GitHub Pages，个人内容只保存在使用者的浏览器中。

https://lunarsh4de.github.io/hk-masters-prep/

## 功能

- 勾选进度、关键待办统计和出发倒计时
- 根据出发日期展示“当前先做”，优先列出本阶段的关键事项
- 行前和抵港后事项分阶段推荐，避免提前混入香港身份证、Landing Slip 等落地流程
- 统一“管理清单”入口，集中新增、整理和删除操作
- 事项与大类支持三点菜单、右键或长按编辑和删除
- 删除事项和大类支持连续撤销，搜索、筛选和布局切换不会打断撤销
- 支持分类排序、拖动事项，以及移动端菜单上移/下移
- 搜索、状态筛选、单/双列和紧凑视图
- 私人备注自动保存在浏览器本地，保存失败时会明确提示
- JSON 导出与导入，支持导入确认、异常数据限制和带时间/来源的上一版本恢复
- 通过系统分享菜单分享完整清单；在 Apple 设备上可从分享面板选择备忘录
- 灰色可选建议，可按个人情况加入 NOL、病历摘要、大额现金申报和租约核验等条件性事项
- 香港入境处、卫生署、海关、港铁、机场及院校攻略入口，并保留小红书经验搜索
- 打印清单和复制进度摘要
- 移动端收起次要概览，让关键待办和清单更早出现

## 本地打开

直接打开 `index.html` 即可使用。为获得与 GitHub Pages 一致的效果，也可以启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 数据说明

清单和备注默认保存在浏览器的 `localStorage` 中，不会自动上传到 GitHub。删除、导入和恢复默认等操作会先建立本地恢复点；写入失败时会取消破坏性操作。恢复点仍属于同一浏览器数据，换浏览器、换设备或清理网站数据前，请使用侧栏或更多菜单中的“导出备份”。

默认内容带版本迁移：网站修正规则性错误时，只更新仍保持旧版原文的内置事项，并保留勾选状态；用户自行改写过的内容不会被覆盖。

## 内容边界

- 内容规则最后核对日期：2026-08-08
- “合理自用药物”与“香港危险药物”分开表述；医生证明不是所有药物的统一要求
- 证件、药品、现金申报和香港身份证使用明确条件；保险、银行、照片和学历文件注明按学校或机构要求
- 小红书仅作为生活经验搜索入口，不用于证明签证、药品、租房、交通或银行规则

## 产品定位

- 从 D 签到香港身份证，一张清单走完港硕抵港前后
- 不是通用行李表，而是面向赴港读硕的行动清单
- 无需注册，可自由修改、备份并分享，个人内容只保存在本机
